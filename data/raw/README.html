12. 한계와 권장 사항

  • 모든 데이터는 합성(Synthetic)입니다. 제품 사양·Error Code·펌웨어 이력·가격·SLA 수치는 교육용 가상 값이며 실제 제품·운영 기준과 무관합니다.
  • 문의 문장은 Category별 영어 원문 템플릿(이메일 7~8종·채팅 4종·전화 메모 1종) 조합과 슬롯 치환으로 만들고, 14개 언어 번역문은 Claude가 직접 작성했고, 자리표시자 보존·누락을 프로그램으로 검사했습니다. 실제 고객 문장보다 표현 다양성이 낮으므로 분류 정확도는 실데이터보다 높게 나올 수 있습니다.
  • 오탈자·약어·여러 문의가 섞인 장문·첨부 내용 같은 실제 문의의 잡음은 일부(복합 의도 약 12%, 채팅체)만 반영했습니다.
  • Priority·Routing·SLA 라벨은 ref/ 규칙을 그대로 적용한 결과이므로, 규칙 학습 여부는 평가할 수 있지만 실제 상담원의 판단 편차는 반영되지 않습니다 (상담원 조정 약 4%만 포함).
  • 실데이터를 확보하면 같은 컬럼 체계로 교체·병합할 수 있도록 필드를 맞춰 두었습니다. 성능 검증의 최종 기준은 실데이터로 잡는 것을 권장합니다.
