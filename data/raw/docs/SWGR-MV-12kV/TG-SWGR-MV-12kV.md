# MV Switchgear Panel 12kV (SWGR-MV-12kV) — Troubleshooting and Error Code Guide

## 1. How to use this guide

Find the error code or symptom in section 2, then follow the detailed procedure in section 3. If the problem persists, contact support with the information listed in section 4.

## 2. Error code and symptom list

| Code | Symptom | Section | Severity |
|---|---|---|---|
| — | Partial discharge alarm in switchgear | 3.1 | P2 |
| — | Partial discharge at cable compartment | 3.2 | P2 |
| — | Cable compartment door cannot be opened | 3.3 | P4 |
| — | Busbar joint overheating | 3.4 | P2 |
| — | Protection relay trip without fault | 3.5 | P2 |

## 3. Troubleshooting procedures

### 3.1 Partial discharge alarm in switchgear

- **Possible cause:** Condensation due to anti-condensation heater off
- **How to check:** PD measurement and humidity check
- **Corrective action:** Restore heater operation and clean insulators
- **Note:** this check normally requires a site visit by qualified personnel.

### 3.2 Partial discharge at cable compartment

- **Possible cause:** Cable termination workmanship defect
- **How to check:** PD localisation; inspect cable termination
- **Corrective action:** Re-terminate cable
- **Note:** this check normally requires a site visit by qualified personnel.

### 3.3 Cable compartment door cannot be opened

- **Possible cause:** Earthing switch not closed (interlock)
- **How to check:** Check earthing switch position indicator
- **Corrective action:** Follow operation sequence: open VCB, rack out, close earthing switch

### 3.4 Busbar joint overheating

- **Possible cause:** Insufficient joint torque
- **How to check:** Thermographic inspection under load
- **Corrective action:** Retorque busbar joints in outage
- **Note:** this check normally requires a site visit by qualified personnel.

### 3.5 Protection relay trip without fault

- **Possible cause:** CT polarity reversed / wrong relay setting
- **How to check:** Secondary injection test; check CT polarity
- **Corrective action:** Correct CT wiring and relay settings
- **Note:** this check normally requires a site visit by qualified personnel.

## 4. Information required when contacting support

- Product model / ordering code
- Serial number (nameplate)
- Error code or symptom displayed
- Operating condition at failure (load, speed, temperature)
- Photos of product and nameplate

## 5. Returning a unit

Hardware failures are handled under an RMA number issued by the Warranty & RMA Desk. Do not ship units without an RMA number.
