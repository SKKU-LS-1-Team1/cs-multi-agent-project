# ESS BMS Controller V3 (ESS-BMS-V3) — Datasheet

## 1. Overview

Rack-level battery management system controller for LFP racks. Product family: Energy storage systems. Lifecycle status: **ACTIVE**.

## 2. Technical specifications

### 2.1 Ratings

| Item | Value |
|---|---|
| Cell chemistry | LFP |
| Cells monitored per rack | Up to 240 cells in series |

### 2.2 Performance and characteristics

| Item | Value |
|---|---|
| Cell voltage accuracy | ±5 mV |
| SOC estimation accuracy | ±3% |

### 2.3 Endurance and communication

| Item | Value |
|---|---|
| Communication | CAN 2.0B (PCS), Modbus TCP (EMS) |

### 2.4 Protection and options

| Item | Value |
|---|---|
| Cell over-voltage protection (default) | 3.65 V |
| Cell over-temperature protection (default) | 55 °C |
