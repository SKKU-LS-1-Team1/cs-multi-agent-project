# Oil-immersed Transformer 1000kVA (TRF-OIL-1000) — Troubleshooting and Error Code Guide

## 1. How to use this guide

Find the error code or symptom in section 2, then follow the detailed procedure in section 3. If the problem persists, contact support with the information listed in section 4.

## 2. Error code and symptom list

| Code | Symptom | Section | Severity |
|---|---|---|---|
| — | Abnormal humming noise | 3.1 | P3 |
| A.BH1 | Buchholz alarm | 3.2 | P2 |
| A.BH2 | Buchholz trip | 3.3 | P1 |
| — | Oil leakage at gasket | 3.4 | P3 |
| — | Secondary voltage too high | 3.5 | P3 |

## 3. Troubleshooting procedures

### 3.1 Abnormal humming noise

- **Possible cause:** Loose core clamping or harmonic load
- **How to check:** Sound level and harmonic measurement
- **Corrective action:** Retighten clamping; apply harmonic filter
- **Note:** this check normally requires a site visit by qualified personnel.

### 3.2 A.BH1 — Buchholz alarm

- **Possible cause:** Air trapped after oil filling
- **How to check:** Gas sample test (air vs fault gas), DGA
- **Corrective action:** Bleed air from Buchholz relay; monitor
- **Note:** this check normally requires a site visit by qualified personnel.

### 3.3 A.BH2 — Buchholz trip

- **Possible cause:** Internal winding fault
- **How to check:** DGA shows acetylene; winding resistance test
- **Corrective action:** Factory repair under warranty claim
- **Note:** this check normally requires a site visit by qualified personnel.
- **Note:** hardware replacement is required; request an RMA (see POL-WARRANTY).
- **Safety:** isolate the equipment immediately and contact support by phone.

### 3.4 Oil leakage at gasket

- **Possible cause:** Gasket damage during transport
- **How to check:** Visual inspection of flanges
- **Corrective action:** Replace gasket and top up oil
- **Replacement part:** Gasket set
- **Note:** this check normally requires a site visit by qualified personnel.

### 3.5 Secondary voltage too high

- **Possible cause:** Off-circuit tap at wrong position
- **How to check:** Measure secondary voltage and check tap
- **Corrective action:** Change tap position in de-energised state

## 4. Information required when contacting support

- Product model / ordering code
- Serial number (nameplate)
- Error code or symptom displayed
- Operating condition at failure (load, speed, temperature)
- Photos of product and nameplate
- Load current / temperature records

## 5. Returning a unit

Hardware failures are handled under an RMA number issued by the Warranty & RMA Desk. Do not ship units without an RMA number.
