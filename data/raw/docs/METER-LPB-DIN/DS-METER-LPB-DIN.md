# DIN Rail Energy Meter (METER-LPB-DIN) — Datasheet

## 1. Overview

DIN-rail direct-connected energy meter up to 80A, MID class B. Product family: Power & energy meters. Lifecycle status: **ACTIVE**.

## 2. Technical specifications

### 2.1 Ratings

| Item | Value |
|---|---|
| Accuracy class | Class 1 (IEC 62053-21) / MID class B |
| Maximum current (direct connection) | 80 A |
| Wiring | 1P2W or 3P4W (model dependent) |

### 2.3 Endurance and communication

| Item | Value |
|---|---|
| Communication | Modbus RTU (RS-485) |
| Pulse output | Open collector, 1000 imp/kWh |

## 3. Installation data

### 3.1 Terminals

- Dimensions (W x H x D): 72 x 90 x 66 (4 modules) mm
- Weight: 0.4 kg
- Degree of protection: IP51 (front)
