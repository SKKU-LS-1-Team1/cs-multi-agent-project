# ELCB 200AF (ELCB-EBN-203c) — Troubleshooting and Error Code Guide

## 1. How to use this guide

Find the error code or symptom in section 2, then follow the detailed procedure in section 3. If the problem persists, contact support with the information listed in section 4.

## 2. Error code and symptom list

| Code | Symptom | Section | Severity |
|---|---|---|---|
| — | Terminal overheating / discoloration | 3.1 | P2 |
| — | Breaker cannot be reset after trip | 3.2 | P4 |
| — | Breaker does not close, mechanism damaged | 3.3 | P2 |
| — | Unwanted earth leakage trip | 3.4 | P3 |
| — | Test button does not trip ELCB | 3.5 | P1 |

## 3. Troubleshooting procedures

### 3.1 Terminal overheating / discoloration

- **Possible cause:** Loose connection or undersized cable
- **How to check:** Thermographic inspection; check tightening torque
- **Corrective action:** Retighten to specified torque; replace damaged terminal
- **Note:** this check normally requires a site visit by qualified personnel.

### 3.2 Breaker cannot be reset after trip

- **Possible cause:** Handle not moved to reset position before ON
- **How to check:** Check handle position (trip / reset)
- **Corrective action:** Push handle fully to OFF/RESET then ON

### 3.3 Breaker does not close, mechanism damaged

- **Possible cause:** Internal mechanism failure
- **How to check:** Handle does not latch after reset
- **Corrective action:** Replace breaker under warranty
- **Note:** hardware replacement is required; request an RMA (see POL-WARRANTY).

### 3.4 Unwanted earth leakage trip

- **Possible cause:** Cumulative leakage current from VFD EMC filters
- **How to check:** Measure leakage current with clamp meter
- **Corrective action:** Change sensitivity setting to 100/300 mA or separate circuits

### 3.5 Test button does not trip ELCB

- **Possible cause:** Residual current sensing circuit failure
- **How to check:** Press test button at rated voltage; no trip
- **Corrective action:** Replace ELCB immediately (safety)
- **Note:** hardware replacement is required; request an RMA (see POL-WARRANTY).
- **Safety:** isolate the equipment immediately and contact support by phone.

## 4. Information required when contacting support

- Product model / ordering code
- Serial number (nameplate)
- Error code or symptom displayed
- Operating condition at failure (load, speed, temperature)
- Photos of product and nameplate
- Load current / temperature records

## 5. Returning a unit

Hardware failures are handled under an RMA number issued by the Warranty & RMA Desk. Do not ship units without an RMA number.
