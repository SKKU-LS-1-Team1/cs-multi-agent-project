# Thermal Overload Relay 22A (RELAY-GMR-22) — Troubleshooting and Error Code Guide

## 1. How to use this guide

Find the error code or symptom in section 2, then follow the detailed procedure in section 3. If the problem persists, contact support with the information listed in section 4.

## 2. Error code and symptom list

| Code | Symptom | Section | Severity |
|---|---|---|---|
| — | Overload relay nuisance trip | 3.1 | P3 |
| — | Overload relay does not trip on overload | 3.2 | P2 |
| — | Overload relay trips on phase loss | 3.3 | P3 |

## 3. Troubleshooting procedures

### 3.1 Overload relay nuisance trip

- **Possible cause:** Setting lower than motor full load current
- **How to check:** Compare setting dial with motor FLC
- **Corrective action:** Adjust setting to motor FLC

### 3.2 Overload relay does not trip on overload

- **Possible cause:** Mechanism failure
- **How to check:** Trip test with test button
- **Corrective action:** Replace relay under warranty
- **Note:** hardware replacement is required; request an RMA (see POL-WARRANTY).

### 3.3 Overload relay trips on phase loss

- **Possible cause:** Upstream fuse blown on one phase
- **How to check:** Measure three phase currents
- **Corrective action:** Replace fuse; check motor

## 4. Information required when contacting support

- Product model / ordering code
- Serial number (nameplate)
- Error code or symptom displayed
- Operating condition at failure (load, speed, temperature)
- Photos of product and nameplate

## 5. Returning a unit

Hardware failures are handled under an RMA number issued by the Warranty & RMA Desk. Do not ship units without an RMA number.
