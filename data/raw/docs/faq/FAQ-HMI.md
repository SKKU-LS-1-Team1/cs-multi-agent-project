# Operator panels (HMI) — Frequently Asked Questions

## Q1. Which products does this FAQ cover?

XGT Panel eXP60 (6") (HMI-XGT-eXP60), XGT iXP90 (10") (HMI-XGT-iXP90)

## Q2. What is the warranty period?

HMI-XGT-eXP60: 24 months; HMI-XGT-iXP90: 24 months. See POL-WARRANTY.

## Q3. What is the standard lead time?

HMI-XGT-eXP60: 4 weeks ex-works; HMI-XGT-iXP90: 4 weeks ex-works. See POL-ORDER.

## Q4. Which certifications are available?

HMI-XGT-eXP60: CE, KC; HMI-XGT-iXP90: CE, UL, KC

## Q5. Where can I get manuals and datasheets?

Each product has a datasheet (DS-), installation guide (IG-), troubleshooting guide (TG-) and release notes (RN-) or maintenance guide (MG-). Documents are in English.

## Q6. What information should I send when reporting a fault?

Product model / ordering code, Serial number (nameplate), Error code or symptom displayed, Operating condition at failure (load, speed, temperature), Photos of product and nameplate, PLC/HMI project backup.

## Q7. How do I return a product?

Request an RMA number first. Returns without RMA are refused. See POL-RETURN.

## Q8. What is the latest firmware?

HMI-XGT-eXP60: 1.62; HMI-XGT-iXP90: 2.08
