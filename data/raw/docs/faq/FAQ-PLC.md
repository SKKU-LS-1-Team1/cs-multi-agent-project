# Programmable logic controllers — Frequently Asked Questions

## Q1. Which products does this FAQ cover?

XGB PLC CPU 16 I/O (PLC-XGB-XBM-DR16S), XGI PLC CPU Universal (PLC-XGI-CPUU)

## Q2. What is the warranty period?

PLC-XGB-XBM-DR16S: 24 months; PLC-XGI-CPUU: 24 months. See POL-WARRANTY.

## Q3. What is the standard lead time?

PLC-XGB-XBM-DR16S: 3 weeks ex-works; PLC-XGI-CPUU: 4 weeks ex-works. See POL-ORDER.

## Q4. Which certifications are available?

PLC-XGB-XBM-DR16S: CE, UL, KC; PLC-XGI-CPUU: CE, UL, KC

## Q5. Where can I get manuals and datasheets?

Each product has a datasheet (DS-), installation guide (IG-), troubleshooting guide (TG-) and release notes (RN-) or maintenance guide (MG-). Documents are in English.

## Q6. What information should I send when reporting a fault?

Product model / ordering code, Serial number (nameplate), Error code or symptom displayed, Operating condition at failure (load, speed, temperature), Photos of product and nameplate, Event / trip log export, PLC/HMI project backup.

## Q7. How do I return a product?

Request an RMA number first. Returns without RMA are refused. See POL-RETURN.

## Q8. What is the latest firmware?

PLC-XGB-XBM-DR16S: 3.20; PLC-XGI-CPUU: 4.50
