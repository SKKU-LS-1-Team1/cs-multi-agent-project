# Energy storage systems — Frequently Asked Questions

## Q1. Which products does this FAQ cover?

ESS PCS 100kW (ESS-PCS-100kW), ESS BMS Controller V3 (ESS-BMS-V3)

## Q2. What is the warranty period?

ESS-PCS-100kW: 36 months; ESS-BMS-V3: 36 months. See POL-WARRANTY.

## Q3. What is the standard lead time?

ESS-PCS-100kW: 10 weeks ex-works; ESS-BMS-V3: 8 weeks ex-works. See POL-ORDER.

## Q4. Which certifications are available?

ESS-PCS-100kW: CE, KC, UL 1741 SB (-U variant); ESS-BMS-V3: CE, KC

## Q5. Where can I get manuals and datasheets?

Each product has a datasheet (DS-), installation guide (IG-), troubleshooting guide (TG-) and release notes (RN-) or maintenance guide (MG-). Documents are in English.

## Q6. What information should I send when reporting a fault?

Product model / ordering code, Serial number (nameplate), Error code or symptom displayed, Operating condition at failure (load, speed, temperature), Photos of product and nameplate, Event / trip log export, Battery SOC / cell temperature at event.

## Q7. How do I return a product?

Request an RMA number first. Returns without RMA are refused. See POL-RETURN.

## Q8. What is the latest firmware?

ESS-PCS-100kW: 2.70; ESS-BMS-V3: 3.50
