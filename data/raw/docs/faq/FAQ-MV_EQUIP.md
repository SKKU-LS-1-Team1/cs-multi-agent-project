# MV breakers & switchgear — Frequently Asked Questions

## Q1. Which products does this FAQ cover?

VCB 25.8kV 1250A (VCB-25kV-1250), MV Switchgear Panel 12kV (SWGR-MV-12kV)

## Q2. What is the warranty period?

VCB-25kV-1250: 24 months; SWGR-MV-12kV: 24 months. See POL-WARRANTY.

## Q3. What is the standard lead time?

VCB-25kV-1250: 12 weeks ex-works; SWGR-MV-12kV: 14 weeks ex-works. See POL-ORDER.

## Q4. Which certifications are available?

VCB-25kV-1250: CE, KEMA type test report; SWGR-MV-12kV: KEMA type test report, CE

## Q5. Where can I get manuals and datasheets?

Each product has a datasheet (DS-), installation guide (IG-), troubleshooting guide (TG-) and release notes (RN-) or maintenance guide (MG-). Documents are in English.

## Q6. What information should I send when reporting a fault?

Product model / ordering code, Serial number (nameplate), Error code or symptom displayed, Operating condition at failure (load, speed, temperature), Photos of product and nameplate.

## Q7. How do I return a product?

Request an RMA number first. Returns without RMA are refused. See POL-RETURN.
