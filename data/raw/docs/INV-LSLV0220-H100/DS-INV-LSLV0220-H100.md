# LSLV H100 22kW VFD (INV-LSLV0220-H100) — Datasheet

## 1. Overview

HVAC / fan & pump VFD 22kW, built-in BACnet & Modbus, fire mode. Product family: Variable frequency drives. Lifecycle status: **ACTIVE**.

## 2. Technical specifications

### 2.1 Ratings

| Item | Value |
|---|---|
| Rated output (normal duty) | 22 kW / 45 A |
| Overload capacity (normal duty) | 120% for 1 minute |

### 2.2 Performance and characteristics

| Item | Value |
|---|---|
| Fire mode | Yes (fault-ignore run, logged) |
| PID controllers | Main PID + 2 external PID |
| Multi-motor control | Up to 5 pumps (MMC) |

### 2.3 Endurance and communication

| Item | Value |
|---|---|
| Built-in communication | BACnet MS/TP, Modbus RTU, Metasys N2 |

### 2.4 Protection and options

| Item | Value |
|---|---|
| Built-in DC reactor | Yes |
