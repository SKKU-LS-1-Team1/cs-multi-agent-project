# XGT Panel eXP60 (6") (HMI-XGT-eXP60) — Firmware Release Notes

## 1. Summary

Latest firmware: **1.62**. Updating to the latest version is recommended for all units.

## 2. Version history

### 2.1 Version 1.62 (2025-10-20)

- Fixed: H.03 project download failure with editor 3.2 or later
- Added: alarm history export to USB as CSV

### 2.2 Version 1.58 (2025-03-24)

- Fixed: screen freeze after ~30 days continuous uptime

### 2.3 Version 1.50 (2024-06-10)

- Baseline OS

## 3. Update procedure

1. Back up parameters / project before updating.
2. Connect the engineering tool (v4.6 or later).
3. Do not switch off power during the update.
4. After the update, verify the version and restore parameters if required.
5. If the update fails, do not power-cycle the unit repeatedly; contact support for the recovery procedure.

## 4. Compatibility

Parameter files from older versions can be loaded; files from newer versions cannot be loaded into older firmware.
