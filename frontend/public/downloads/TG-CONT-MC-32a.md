# Magnetic Contactor 32A (CONT-MC-32a) — Troubleshooting and Error Code Guide

## 1. How to use this guide

Find the error code or symptom in section 2, then follow the detailed procedure in section 3. If the problem persists, contact support with the information listed in section 4.

## 2. Error code and symptom list

| Code | Symptom | Section | Severity |
|---|---|---|---|
| — | Contactor chattering | 3.1 | P3 |
| — | Contactor coil burnt | 3.2 | P3 |
| — | Main contacts welded | 3.3 | P2 |

## 3. Troubleshooting procedures

### 3.1 Contactor chattering

- **Possible cause:** Control voltage drops below pick-up level
- **How to check:** Measure coil voltage during pick-up
- **Corrective action:** Fix control supply capacity / cable length

### 3.2 Contactor coil burnt

- **Possible cause:** Coil voltage different from supply voltage
- **How to check:** Compare coil nameplate with supply
- **Corrective action:** Replace coil with correct voltage
- **Replacement part:** Coil

### 3.3 Main contacts welded

- **Possible cause:** Short circuit without proper SCPD coordination
- **How to check:** Review coordination type (Type 1/2) with upstream breaker
- **Corrective action:** Replace contactor; apply Type 2 coordination
- **Note:** hardware replacement is required; request an RMA (see POL-WARRANTY).

## 4. Information required when contacting support

- Product model / ordering code
- Serial number (nameplate)
- Error code or symptom displayed
- Operating condition at failure (load, speed, temperature)
- Photos of product and nameplate

## 5. Returning a unit

Hardware failures are handled under an RMA number issued by the Warranty & RMA Desk. Do not ship units without an RMA number.
