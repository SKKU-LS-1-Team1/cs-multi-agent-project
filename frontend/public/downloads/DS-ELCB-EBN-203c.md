# ELCB 200AF (ELCB-EBN-203c) — Datasheet

## 1. Overview

Earth leakage circuit breaker 200A frame, selectable sensitivity. Product family: Low-voltage circuit breakers. Lifecycle status: **ACTIVE**.

## 2. Technical specifications

### 2.1 Ratings

| Item | Value |
|---|---|
| Rated current (In) | 125, 150, 175, 200 A |

### 2.2 Performance and characteristics

| Item | Value |
|---|---|
| Ultimate breaking capacity Icu at AC 415 V | 37 kA |

### 2.4 Protection and options

| Item | Value |
|---|---|
| Rated residual operating current IΔn | 30 / 100 / 300 / 500 mA selectable |
| Residual current type | Type AC (Type A optional) |
| Operating time at IΔn | ≤ 0.1 s (instantaneous setting) |
| Test button operating voltage range | AC 200-460 V |
