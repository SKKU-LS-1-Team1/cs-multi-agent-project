# Solar Inverter 25kW (PV-INV-SOLAR-25) — Firmware Release Notes

## 1. Summary

Latest firmware: **1.90**. Updating to the latest version is recommended for all units.

## 2. Version history

### 2.1 Version 1.90 (2025-12-08)

- Added: reactive power Q(U) curve
- Fixed: Wi-Fi dongle reconnect failure after router reboot

### 2.2 Version 1.82 (2025-04-14)

- Fixed: S.01 false insulation fault at sunrise with humidity > 95%

### 2.3 Version 1.70 (2024-09-09)

- Baseline release

## 3. Update procedure

1. Back up parameters / project before updating.
2. Connect the engineering tool (v4.6 or later).
3. Do not switch off power during the update.
4. After the update, verify the version and restore parameters if required.
5. If the update fails, do not power-cycle the unit repeatedly; contact support for the recovery procedure.

## 4. Compatibility

Parameter files from older versions can be loaded; files from newer versions cannot be loaded into older firmware.
