# LSLV S100 7.5kW VFD (INV-LSLV0075-S100) — Datasheet

## 1. Overview

General purpose VFD 7.5kW, 3-phase 380-480V, sensorless vector. Product family: Variable frequency drives. Lifecycle status: **ACTIVE**.

## 2. Technical specifications

### 2.1 Ratings

| Item | Value |
|---|---|
| Rated output (heavy duty) | 7.5 kW / 16 A |
| Input voltage | 3-phase AC 380-480 V (-15% to +10%), 50/60 Hz |
| Overload capacity (heavy duty) | 150% for 1 minute |

### 2.2 Performance and characteristics

| Item | Value |
|---|---|
| Control method | V/F, slip compensation, sensorless vector |
| Output frequency range | 0.01-400 Hz |

### 2.3 Endurance and communication

| Item | Value |
|---|---|
| Built-in communication | RS-485 Modbus RTU / LS INV protocol |

### 2.4 Protection and options

| Item | Value |
|---|---|
| Safe Torque Off | STO, SIL3 / PLe |
| Built-in EMC filter | Category C3 |
| Braking | Built-in braking transistor (external resistor) |
