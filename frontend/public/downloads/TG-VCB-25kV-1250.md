# VCB 25.8kV 1250A (VCB-25kV-1250) — Troubleshooting and Error Code Guide

## 1. How to use this guide

Find the error code or symptom in section 2, then follow the detailed procedure in section 3. If the problem persists, contact support with the information listed in section 4.

## 2. Error code and symptom list

| Code | Symptom | Section | Severity |
|---|---|---|---|
| — | VCB spring not charging | 3.1 | P2 |
| — | VCB fails to close electrically | 3.2 | P2 |
| — | VCB contact wear indicator at limit | 3.3 | P3 |
| — | Protection relay trip without fault | 3.4 | P2 |

## 3. Troubleshooting procedures

### 3.1 VCB spring not charging

- **Possible cause:** Charging motor failure
- **How to check:** Check control supply and motor current
- **Corrective action:** Replace charging motor
- **Replacement part:** Charging motor
- **Note:** this check normally requires a site visit by qualified personnel.

### 3.2 VCB fails to close electrically

- **Possible cause:** Closing coil burnt
- **How to check:** Measure closing coil resistance
- **Corrective action:** Replace closing coil
- **Replacement part:** Closing coil
- **Note:** this check normally requires a site visit by qualified personnel.

### 3.3 VCB contact wear indicator at limit

- **Possible cause:** Vacuum interrupter end of electrical life
- **How to check:** Check contact wear indicator; vacuum integrity test
- **Corrective action:** Replace vacuum interrupter
- **Replacement part:** Vacuum interrupter
- **Note:** this check normally requires a site visit by qualified personnel.

### 3.4 Protection relay trip without fault

- **Possible cause:** CT polarity reversed / wrong relay setting
- **How to check:** Secondary injection test; check CT polarity
- **Corrective action:** Correct CT wiring and relay settings
- **Note:** this check normally requires a site visit by qualified personnel.

## 4. Information required when contacting support

- Product model / ordering code
- Serial number (nameplate)
- Error code or symptom displayed
- Operating condition at failure (load, speed, temperature)
- Photos of product and nameplate

## 5. Returning a unit

Hardware failures are handled under an RMA number issued by the Warranty & RMA Desk. Do not ship units without an RMA number.
